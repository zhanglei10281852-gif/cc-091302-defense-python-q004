# 军械库出入核验

该项目服务于国防安全业务，负责军械库出入核验相关信息的规范化处理与留痕。

运行环境：Python 3.11，仅使用标准库。代码位于 `src` 目录，事件日志以 JSON
按部署环境指定路径落盘（构造 `Service(store_path=...)`）。

## 能力

- **主数据维护**：装备编码、名称、存放区、所需资质、双人双控标记、领用时限；
  人员资质（含有效期）、授权区域、角色（军械主官 / 安全审计）。
- **门禁刷卡**：按设备时间入链保存；重复刷卡（同一事件号或同人同闸同方向
  30 秒内）只关联原事件，不新增记录；越权区域刷卡拒绝并留痕。
- **业务操作**（均须关联本人授权入场刷卡）：
  - 领用：校验资质有效期、区域授权、逾期未还、在架状态；双控装备须第二名
    持有效资质且获授权的复核人，缺人或同人操作一律阻止。
  - 归还：超过领用时限时普通通道关闭，须由军械主官 + 第三名合格复核人走
    超时归还异常通道，记录迟滞时长与原因。
  - 移库：在架装备方可移库；经办与复核人须同时获源区/目标区授权。
  - 盘点：开始 → 逐件上报 → 双人确认；自动生成 `PRESENT / MISSING /
    LOCATION_MISMATCH / UNEXPECTED_PRESENT` 差异结论；双控装备差异要求两名
    确认人均持有效资质。
- **离线补传**：按设备时间回放；重复提交幂等关联原事件；与**已确认**盘点
  结果冲突的记录进入隔离区（`applied=false` + `quarantine_reasons`），
  绝不覆盖已确认结论（缺失装备不会被补传的"领用"变成借出）。
- **审计**：每台设备独立哈希链（`prev_hash` + 内容哈希），可按装备或人员
  抽取按设备时间排序的不可篡改时间线，任何篡改在 `verify_timeline()` 暴露；
  导出时按核查焦点最小化身份信息（非核查对象匿名、证件号掩码，仅
  `security_audit` 角色可见明文）。

被策略阻止的实时操作会先写入 `POLICY_DENIAL` 留证事件再抛出
`PolicyViolation`，异常上携带结构化原因码列表。

## 验证

```bash
python3 -m tests.smoke
```

覆盖：正常领用归还、重复刷卡、资质失效、缺少/不合格复核人、超时归还双
通道、移库授权、盘点差异确认与离线冲突隔离、落盘重载、篡改检测、时间线
脱敏导出、补传幂等。
